CMS connection

This dashboard requires a Supabase project, the SQL migration in supabase/schema.sql, and public project URL/anon key in supabase-config.js. Never put a service-role key in browser code.

  1. Create a Supabase project.
  2. Run the supplied SQL migration.
  3. Invite staff accounts and assign roles in the profiles table.
  4. Copy supabase-config.example.js to supabase-config.js and enter the project URL and anon key.
  5. Deploy again. The CMS will then authenticate and load database records.
